# GymPro Monetization Strategy

GymPro uses a no-ads model. Revenue comes from paid features that serious users
naturally need after they build a workout habit.

## Pricing

| Tier | Price | Included |
| --- | --- | --- |
| Free | ₹0 forever | 3 workouts saved, basic stats, 50 exercises |
| Pro Monthly | ₹199/month | Unlimited workouts, advanced charts, 500+ exercises, custom exercises, CSV/PDF export, AI workout plans |
| Pro Annual | ₹999/year | Same as Pro Monthly, positioned as the primary offer with roughly 58% savings |

## Revenue Streams

| Stream | Notes |
| --- | --- |
| Pro subscription | Core revenue. Lock advanced features behind a paywall and push annual first. Target: 100 users x ₹999/year = ₹99,900/year. |
| Trainer marketplace v2 | Certified trainers sell custom plans inside the app. GymPro takes 20% commission on each sale. |
| Equipment affiliate links | Exercise picker can include a low-friction "Buy equipment" link for dumbbells, bands, belts, and accessories. Target 3-8% commission per sale. |
| Gym partnerships v2 | Local gyms pay to be listed as partner gyms. Target ₹2,000-₹5,000 per gym per month. |

## Year 1 Conservative Estimate

| Item | Estimate |
| --- | ---: |
| 500 free users | ₹0 |
| 80 Pro monthly users at ₹199 | ₹1,91,040/year |
| 40 Pro annual users at ₹999 | ₹39,960/year |
| Affiliate commissions | ~₹15,000/year |
| Google Play 15% cut | -₹34,650 |
| Net estimated revenue | ~₹2,11,350/year |

## Product Rules

- Do not add banner ads, interstitial ads, or rewarded ads.
- Show upgrade prompts only when users hit a limit or open a Pro-only feature.
- Keep Free useful enough to build trust: 3 workouts, basic stats, and starter exercises.
- Make annual Pro the preferred plan because it improves retention and cash flow.
- Add v2 revenue streams only after the workout tracker has healthy retention.
